# CareFlow Power BI Dashboard

## Project Overview
CareFlow is a clinical pathway process-mining project that analyzes patient event logs to identify workflow patterns, waiting times, and potential bottlenecks.

## My Responsibility
My role is dashboard development using Microsoft Power BI.

## Dashboard Objectives
- Display total patient cases and recorded events.
- Analyze patient waiting times.
- Identify and compare loop-back cases.
- Visualize activity frequencies and patient pathways.
- Provide interactive filters for exploring the dataset.

## Dataset
The project uses the provided synthetic CareFlow dataset containing patient events, patient summaries, and a data dictionary.
